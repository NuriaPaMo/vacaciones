| Status        | Draft                                   |

## Brief Description

A Department Manager generates a coverage report showing vacation coverage percentages by day or
week for a selected date range and organizational scope. Periods exceeding the threshold (70%) are
highlighted. The report can be compared across departments/projects and exported.

## Stakeholders and Interests

| Stakeholder        | Interest                                                       |
| ------------------ | -------------------------------------------------------------- |
| Department Manager | Capacity planning for peak seasons                             |
| HR Operations      | Ensure coverage compliance across departments                  |

## Preconditions

1. User is authenticated with DM or Administrator role
2. CapacitySnapshot records exist for the queried period

## Postconditions (Success Guarantees)

1. Coverage report rendered with threshold highlighting
2. Export generated on request

## Triggers

- User navigates to "Reports → Coverage"

---

## Main Success Scenario

| Step | Actor             | System                                                          |
| ---- | ----------------- | --------------------------------------------------------------- |
| 1    | DM navigates to "Reports → Coverage" |                                          |
| 2    |                   | System shows: date range, granularity (day/week), department/project selector |
| 3    | DM sets: July 2026, weekly granularity, full department |                         |
| 4    | DM clicks "Generate" |                                                          |
| 5    |                   | System queries CapacitySnapshot aggregated by week              |
| 6    |                   | System renders table: week, total employees, on vacation, percentage |
| 7    |                   | Weeks above 70% highlighted in red; 65-70% in orange            |
| 8    | DM exports to Excel |                                                            |

## Special Requirements

- **Performance**: Report generation < 5 seconds
- **Threshold**: Same as configured ThresholdConfig (synced from F-003 configuration)
- **Export**: Excel includes color formatting; PDF includes charts

## Technology and Data Variations

- **Data Source**: CapacitySnapshot table (pre-computed)
- **Granularity**: Day-level or week-level aggregation

## Frequency of Occurrence

- Expected: ~1 report/manager/month; more frequent before peak seasons
