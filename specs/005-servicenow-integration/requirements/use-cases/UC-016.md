## Brief Description

A .NET BackgroundService runs nightly at 4:00 AM and exports all newly-approved (and newly-
cancelled) vacation records to ServiceNow via REST API. Only fully-approved requests (both levels)
are exported. Failed records are retried and admins alerted on persistent failures.

## Stakeholders and Interests

| Stakeholder        | Interest                                                       |
| ------------------ | -------------------------------------------------------------- |
| Scheduler (System) | Reliable export with delta sync and error recovery             |
| ServiceNow         | Accurate vacation records for resource planning                |
| Administrator      | Visibility into export health; manual retry capability         |
| Compliance         | All exports auditable via ExportJob/ExportRecord               |

## Preconditions

1. AD sync (UC-012) has completed for the same night
2. Managed Identity has ServiceNow API credentials in Key Vault
3. VacationRequests with Status=Approved AND IsExported=false exist

## Postconditions (Success Guarantees)

1. ExportJob record created (Status=Completed, counts)
2. Each exported request: IsExported=true, ExportedAt=now, ServiceNowId=<id>
3. Cancelled+previously-exported requests: ServiceNow record updated/deleted
4. OTel metrics published to Azure Monitor

## Triggers

- Scheduled at 4:00 AM daily (PeriodicTimer, after AD sync window)

---

## Main Success Scenario

| Step | Actor                   | System                                                          |
| ---- | ----------------------- | --------------------------------------------------------------- |
| 1    | PeriodicTimer fires at 4:00 AM |                                                          |
| 2    |                         | System creates ExportJob (Status=InProgress)                    |
| 3    |                         | System queries: requests where Status=Approved AND IsExported=false |
| 4    |                         | System queries: requests where Status=Cancelled AND IsExported=true (to delete in SN) |
| 5    |                         | For each new approved request: POST to ServiceNow Table API     |
| 6    |                         | On success: mark IsExported=true, store ServiceNowId            |
| 7    |                         | For each cancelled request: DELETE/PATCH in ServiceNow          |
| 8    |                         | System updates ExportJob counts (Exported, Updated, Deleted, Errors) |
| 9    |                         | System sets ExportJob.Status = Completed                        |
| 10   |                         | System publishes OTel metrics                                   |

## Extensions (Alternative Flows)

### 5a. ServiceNow API Call Fails

| Step  | Actor          | System                                                        |
| ----- | -------------- | ------------------------------------------------------------- |
| 5a.1  |                | ServiceNow returns 4xx or 5xx                                 |
| 5a.2  |                | System creates ExportRecord with Status=Failed, ErrorMessage  |
| 5a.3  |                | System retries up to 3 times (backoff: 1s, 5s, 30s)          |
| 5a.4  |                | After 3 failures: ExportRecord.Status = PermanentFailure       |
| 5a.5  |                | Batch continues with remaining records                        |

### \*a. Error Rate > 5%

| Step  | Actor          | System                                                        |
| ----- | -------------- | ------------------------------------------------------------- |
| \*a.1 |                | ExportJob error rate > 5%                                     |
| \*a.2 |                | System publishes ExportAlert event → admin email via F-006    |

### 2a. ServiceNow Completely Unavailable (Circuit Breaker)

| Step  | Actor          | System                                                        |
| ----- | -------------- | ------------------------------------------------------------- |
| 2a.1  |                | First 3 API calls all fail with 503                           |
| 2a.2  |                | System opens circuit breaker; aborts batch                    |
| 2a.3  |                | ExportJob.Status = Failed                                     |
| 2a.4  |                | Admin alert sent; records remain IsExported=false for next run |

## Special Requirements

- **Idempotency**: Re-running export must not create duplicate ServiceNow records
- **Security**: ServiceNow credentials retrieved from Key Vault via Managed Identity
- **GDPR**: Only minimum necessary fields exported to ServiceNow
- **Performance**: Complete within 15 minutes for typical batch (50 records)

## Technology and Data Variations

- **Protocol**: ServiceNow Table API (REST, JSON)
- **Auth**: OAuth 2.0 client credentials flow (ServiceNow OAuth provider)
- **Idempotency Key**: VacationRequest.Id used as external reference in ServiceNow

## Frequency of Occurrence

- Runs: once per day (nightly)
- Expected batch size: 20–50 records on normal days; up to 200 during summer
