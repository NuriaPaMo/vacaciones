# Use Case: Executive Dashboard

| ------------- | --------------------------------------- |

| User Story    | US-010                                  |

| Level         | User Goal                               |
| Status        | Draft                                   |

## Brief Description

A Department Manager opens the dashboard to get an at-a-glance view of key vacation metrics:
current vacation count, available employees, pending approvals, over-requested periods in the next
90 days, and average approval time. They can export the dashboard as PDF or Excel.

## Stakeholders and Interests

| Stakeholder        | Interest                                                       |
| ------------------ | -------------------------------------------------------------- |
| Department Manager | Quick situational awareness for decision-making                |
| Project Manager    | Project-scoped KPIs for their own team                        |
| Executive          | High-level export for reporting                                |

## Preconditions

1. User is authenticated with DM or PM role
2. VacationRequest and CapacitySnapshot data exists

## Postconditions (Success Guarantees)

1. Dashboard rendered in < 2 seconds with accurate real-time data
2. All widgets show data scoped to authenticated user's authority

## Triggers

- User navigates to "/" (home) or "Dashboard" in the application

---

## Main Success Scenario

| Step | Actor             | System                                                          |
| ---- | ----------------- | --------------------------------------------------------------- |
| 1    | DM opens the application |                                                          |
| 2    |                   | System renders dashboard with scoped KPI widgets                |
| 3    |                   | Widget 1: Current vacation count (employees away today)         |
| 4    |                   | Widget 2: Available employees (total − on vacation)             |
| 5    |                   | Widget 3: Pending approvals count (awaiting DM action)          |
| 6    |                   | Widget 4: Over-requested periods in next 90 days (list of dates)|
| 7    |                   | Widget 5: Average approval time (last 30 days)                  |
| 8    | DM reviews widgets |                                                              |
| 9    | DM clicks an over-requested period alert |                                        |
| 10   |                   | System navigates to heat map for that specific period (UC-009)  |

---

## Special Requirements

- **Performance**: Full dashboard load < 2 seconds
- **Security**: Data scoped to user's role (DM=department, PM=project)
- **Data Freshness**: Data reflects real-time state (no stale cache > 5 minutes)

## Technology and Data Variations

- **Caching**: Dashboard aggregates cached in Redis (TTL 5 min); invalidated on approvals
- **Export**: Server-side PDF generation using Reporting library

## Frequency of Occurrence

- Expected: Every manager opens dashboard at least once/day = ~60 views/day
