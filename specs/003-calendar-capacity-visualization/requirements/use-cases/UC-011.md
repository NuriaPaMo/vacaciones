# Use Case: Organizational Level Selection

| ------------- | --------------------------------------- |

| User Story    | US-011                                  |
| Feature       | F-003 (gh#4)                            |
| Primary Actor | Manager (PM or DM)                      |
| Scope         | Calendar & Capacity Visualization       |
| Level         | Subfunction                             |
| Status        | Draft                                   |

## Brief Description

A manager selects the organizational level (Department, Project, or Team) and a time period (days
or weeks) to query vacation coverage data. The system returns the count and percentage of employees
on vacation for the selected level and period.

## Stakeholders and Interests

| Stakeholder        | Interest                                                       |
| ------------------ | -------------------------------------------------------------- |
| Department Manager | Query any level to understand coverage at different granularities |
| Project Manager    | Query project and team levels for planning decisions           |

## Preconditions

1. User is authenticated with PM or DM role
2. Organizational hierarchy synced from AD (F-004)
3. VacationRequest records exist

## Postconditions (Success Guarantees)

1. Query result returned: total employees, on vacation, percentage
2. Result displayed in calendar or heat map context

## Triggers

- User changes the "Level" or "Period" selector in the calendar/heat map view

---

## Main Success Scenario

| Step | Actor             | System                                                          |
| ---- | ----------------- | --------------------------------------------------------------- |
| 1    | Manager opens calendar or heat map view |                                          |
| 2    |                   | System shows level selector (Department / Project / Team) and period selector |
| 3    | Manager selects "Project" level and "Week" period |                               |
| 4    |                   | System queries: employees in project, requests covering the week |
| 5    |                   | System calculates: total=50, on_vacation=12, percentage=24%     |
| 6    |                   | System re-renders heat map / calendar with project-level data   |
| 7    | Manager changes to "Department" level |                                          |
| 8    |                   | System recalculates with all department employees               |
| 9    |                   | System re-renders                                               |

---

## Extensions (Alternative Flows)

### 3a. PM Tries to Select Department Level

| Step  | Actor          | System                                                       |
| ----- | -------------- | ------------------------------------------------------------ |
| 3a.1  |                | "Department" level is disabled for PM role (greyed out)      |
| 3a.2  | PM can only select Project or Team                                              |

### 4a. Team Has Zero Employees

| Step  | Actor          | System                                                       |
| ----- | -------------- | ------------------------------------------------------------ |
| 4a.1  |                | System returns: total=0, on_vacation=0, percentage=N/A       |
| 4a.2  |                | System renders empty state for that level                    |

---

## Special Requirements

- **Performance**: Level switch re-render < 500ms
- **Security**: PM limited to Project/Team levels; DM can access all levels

## Technology and Data Variations

- **Period types**: days (specific day) or weeks (Mon–Fri range)
- **Data source**: CapacitySnapshot table (pre-aggregated by level)

## Frequency of Occurrence

- Expected: ~10 level-switch interactions/manager/session
