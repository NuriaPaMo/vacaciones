## Brief Description

A Department Manager views a heat map of vacation coverage percentages by time period. Each cell is
color-coded by threshold level (Normal/Moderate/Warning/Critical). Clicking a Critical cell drills
down to see which employees are on vacation in that period.

## Stakeholders and Interests

| Stakeholder        | Interest                                                       |
| ------------------ | -------------------------------------------------------------- |
| Department Manager | Proactively identify over-requested periods before approving   |
| Project Manager    | See project-level capacity before approving new requests       |
| Employee           | Understand if their requested period is over-requested         |

## Preconditions

1. User is authenticated with DM or PM role
2. CapacitySnapshot records exist for the visible date range
3. ThresholdConfig configured (default: Warning=65%, Critical=70%)

## Postconditions (Success Guarantees)

1. Heat map rendered with correct color coding per threshold
2. Drill-down shows correct employee list for selected period

## Triggers

- User clicks "Capacity" or "Heat Map" in navigation
- User navigates from Dashboard alert to heat map

## Main Success Scenario

| Step | Actor                   | System                                                         |
| ---- | ----------------------- | -------------------------------------------------------------- |
| 1    | DM navigates to "Capacity Heat Map" |                                                   |
| 2    |                         | System fetches CapacitySnapshot for current month, department  |
| 3    |                         | System renders heat map: days on X-axis, value = coverage %    |
| 4    |                         | 0–50% → green; 51–64% → yellow; 65–70% → orange; >70% → red   |
| 5    | DM scans heat map for red cells |                                                       |
| 6    | DM clicks on a red cell (Critical period) |                                           |
| 7    |                         | System fetches employees on vacation for that specific day     |
| 8    |                         | System renders drill-down panel: employee list, status, dates  |
| 9    |                         | System suggests alternative dates with lower capacity (nearest weeks below threshold) |

## Special Requirements

- **Performance**: Heat map render < 1 second (from Redis cache)
- **Accessibility**: Color alone must not be the only indicator (add % label in each cell)
- **Security**: DM sees department; PM sees their project only

## Technology and Data Variations

- **Data Source**: CapacitySnapshot table (pre-computed) → Redis cache
- **Cache Invalidation**: On every approval/cancellation event

## Frequency of Occurrence

- Expected: ~5 heat map views/manager/day = ~500 views/day
- Peak: During approval season (PM/DM checking before acting)
