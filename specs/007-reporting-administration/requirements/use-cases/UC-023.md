## Brief Description

A Department Manager generates a vacation history report filtered by date range, employee,
department, and status. The report is rendered in the UI and can be exported to CSV, Excel, or PDF.

## Stakeholders and Interests

| Stakeholder        | Interest                                                       |
| ------------------ | -------------------------------------------------------------- |
| Department Manager | Historical analysis of vacation patterns; executive reporting  |
| Administrator      | Access to all departments for compliance purposes              |
| Auditor            | Export for compliance audit                                    |

## Preconditions

1. User is authenticated with DM or Administrator role
2. VacationRequest records exist for the queried period

## Postconditions (Success Guarantees)

1. Report rendered in < 5 seconds with accurate data
2. Export file generated and downloaded on request

## Triggers

- User navigates to "Reports → Vacation History"

---

## Main Success Scenario

| Step | Actor             | System                                                          |
| ---- | ----------------- | --------------------------------------------------------------- |
| 1    | DM navigates to "Reports → Vacation History" |                                   |
| 2    |                   | System shows filter panel: date range, department, employee, status |
| 3    | DM sets filter: current year, all employees, all statuses |                       |
| 4    | DM clicks "Generate Report" |                                                   |
| 5    |                   | System queries VacationRequest with applied filters             |
| 6    |                   | System renders table: employee, dates, days, status, approvers  |
| 7    | DM reviews the report |                                                          |
| 8    | DM clicks "Export → Excel" |                                                    |
| 9    |                   | System generates XLSX file and triggers browser download        |

## Special Requirements

- **Performance**: Report generation < 5 seconds for 1 year of data
- **Security**: DM can only access their department's data
- **Export**: CSV (raw data), Excel (formatted), PDF (printable with headers/footers)
- **Pagination**: Results paginated at 50 rows per page in UI

## Technology and Data Variations

- **Export Storage**: Generated files stored in Azure Blob Storage (temp, 1h TTL)
- **Large Reports**: Background generation for > 1,000 rows with download link via email

## Frequency of Occurrence

- Expected: ~2 reports/manager/month = ~20 reports/month
- Peak: January (year-end review) and September (planning season)
