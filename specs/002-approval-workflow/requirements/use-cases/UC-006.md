# Use Case: Approval Delegation

## Brief Description

An approver (PM or DM) configures delegation of their approval authority to another user for a
specified period (temporary) or indefinitely (permanent). The delegate can then approve or reject
requests on behalf of the original approver, with full audit trail showing both identities.

## Stakeholders and Interests

| Stakeholder        | Interest                                                         |
| ------------------ | ---------------------------------------------------------------- |
| Approver (PM/DM)   | Ensure approvals continue while unavailable (own vacation, etc.) |
| Delegate           | Clearly see delegated requests in their queue                    |
| Employee           | No delays due to absent approvers                                |
| Compliance         | Delegated actions traceable to both delegate and delegator       |

## Preconditions

1. Approver is authenticated with PM or DM role
2. Proposed delegate is a designated backup approver from the same project (PM) or department (DM)
3. No existing active delegation for this approver (max one at a time)
4. Delegate cannot be a regular Employee; must hold PM or DM role

## Postconditions (Success Guarantees — Create Delegation)

1. Delegation record created with: DelegatorId, DelegateId, Scope, StartDate, EndDate, IsActive=true
2. Delegate begins seeing delegated requests in their approval queue
3. Delegation audit entry created

## Postconditions (Success Guarantees — Revoke Delegation)

1. Delegation.IsActive set to false, EndDate = now (if permanent)
2. Delegate immediately loses access to the delegated requests
3. Revocation audit entry created

## Triggers

- Approver navigates to "My Delegation Settings" and creates or revokes a delegation

## Main Success Scenario — Create Temporary Delegation

| Step | Actor                    | System                                                       |
| ---- | ------------------------ | ------------------------------------------------------------ |
| 1    | Approver navigates to "Delegation Settings" |                                         |
| 2    |                          | System shows current delegation status (none or active)      |
| 3    | Approver clicks "Add Delegation" |                                                      |
| 4    |                          | System renders delegation form: delegate search, start date, end date |
| 5    | Approver searches for and selects a delegate |                                      |
| 6    | Approver sets start and end dates |                                                  |
| 7    | Approver clicks "Save Delegation" |                                                  |
| 8    |                          | System validates: no circular delegation, delegate in scope, max 1 active |
| 9    |                          | System creates Delegation record (IsActive=true)             |
| 10   |                          | System shows: "Delegation created. [Delegate Name] will manage your approvals from [Start] to [End]" |

### Permanent Delegation (no end date)

| Step | Actor                    | System                                                       |
| ---- | ------------------------ | ------------------------------------------------------------ |
| 6    | Approver leaves end date blank |                                                        |
| 9    |                          | System creates Delegation with EndDate = null                |
| 10   |                          | System shows: "Permanent delegation created until revoked"   |

## Extensions (Alternative Flows)

### 8a. Circular Delegation Detected

| Step  | Actor          | System                                                       |
| ----- | -------------- | ------------------------------------------------------------ |
| 8a.1  |                | System detects A → B → A circular chain                     |
| 8a.2  |                | System shows error: "Circular delegation not allowed"        |
| 8a.3  | Approver selects a different delegate |                                           |

### 8b. Duplicate Active Delegation

| Step  | Actor          | System                                                       |
| ----- | -------------- | ------------------------------------------------------------ |
| 8b.1  |                | System detects an existing active delegation for this approver |
| 8b.2  |                | System shows: "You already have an active delegation. Revoke it first." |

### Revoke Scenario

| Step | Actor                    | System                                                       |
| ---- | ------------------------ | ------------------------------------------------------------ |
| 1    | Approver clicks "Revoke" on active delegation |                                    |
| 2    |                          | System shows confirmation dialog                             |
| 3    | Approver confirms |                                                                  |
| 4    |                          | System sets Delegation.IsActive = false, EndDate = now        |
| 5    |                          | System shows: "Delegation revoked. You are now the sole approver." |

### \*a. Delegation Expires Automatically

| Step  | Actor          | System                                                       |
| ----- | -------------- | ------------------------------------------------------------ |
| \*a.1 |                | Background job detects EndDate has passed                    |
| \*a.2 |                | System sets Delegation.IsActive = false                      |
| \*a.3 |                | Original approver regains sole authority                     |

### \*b. Auto-Delegation When PM Goes on Vacation (CL-009 resolved)

| Step  | Actor          | System                                                       |
| ----- | -------------- | ------------------------------------------------------------ |
| \*b.1 |                | PM's own vacation request is fully approved                  |
| \*b.2 |                | System checks: does PM have a designated backup?             |
| \*b.3 |                | If yes: system auto-creates Delegation for the vacation period |
| \*b.4 |                | If no: system alerts PM and admin: "No backup approver configured" |

---

## Special Requirements

- **Security**: Delegate must be a designated backup approver with PM or DM role within the same scope
- **Audit**: All delegation creates/revocations logged with timestamp and actor
- **Real-time**: Delegate gains/loses access immediately (no cache delay)
- **Auto-delegation**: When a PM's vacation is approved, system auto-creates delegation if backup exists

## Technology and Data Variations

- **Expiry Check**: Background job runs every 30 minutes to expire delegations

## Frequency of Occurrence

- Expected: ~50 delegations/year (approvers taking vacation)
- Peaks: Before summer and December holidays
