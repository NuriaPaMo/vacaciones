## Brief Description

An administrator or auditor searches and views the complete immutable audit log of all system
actions. The log captures user actions (create, approve, reject, cancel, delegate, configure) and
system events (integrations, batch jobs). Records are retained for 7 years and exportable.

## Stakeholders and Interests

| Stakeholder        | Interest                                                       |
| ------------------ | -------------------------------------------------------------- |
| Administrator      | Investigate issues; trace who did what and when               |
| Auditor            | Demonstrate compliance with vacation policy                    |
| Legal/Compliance   | 7-year immutable record per regulatory requirement             |

## Preconditions

1. User is authenticated with Administrator or Auditor role
2. AuditEntry records exist

## Postconditions (Success Guarantees)

1. Audit log displayed with accurate, unmodified records
2. Export generated on request

## Triggers

- Administrator navigates to "Admin → Audit Trail"
- Auditor navigates to "Audit" section

---

## Main Success Scenario

| Step | Actor             | System                                                          |
| ---- | ----------------- | --------------------------------------------------------------- |
| 1    | Admin navigates to "Admin → Audit Trail" |                                      |
| 2    |                   | System shows search filters: user, date range, action type, entity type |
| 3    | Admin sets filter: last 7 days, all users, action=Approve |                       |
| 4    | Admin clicks "Search" |                                                          |
| 5    |                   | System queries AuditEntry with filters; paginates at 50/page    |
| 6    |                   | System renders table: timestamp, user, action, entity, before/after |
| 7    | Admin clicks on an entry for full detail |                                       |
| 8    |                   | System renders entry detail including JSON before/after values  |
| 9    | Admin clicks "Export to CSV" |                                                   |
| 10   |                   | System generates CSV of current search results and triggers download |

## Special Requirements

- **Immutability**: AuditEntry records are append-only; no UPDATE or DELETE
- **Retention**: 7 years (regulatory requirement)
- **Performance**: Search < 2 seconds across 1 million entries (index on: timestamp, userId, actionType)
- **Security**: Only Administrator and Auditor roles

## Technology and Data Variations

- **Storage**: AuditEntry in Azure SQL; consider partitioning by year for 7-year retention
- **JSON**: Before/after values stored as JSON; rendered in human-readable diff view

## Frequency of Occurrence

- Expected: ~1 audit search/admin/week; ~1 export/month for compliance review

## Open Issues

- Q-021: Should audit log be stored in a separate database for performance isolation?
- Q-024: Is there a specific retention policy beyond 7 years (archival to cold storage)?
