## Brief Description

An administrator monitors the health of AD synchronization jobs from the admin panel. They can view
last sync status, review 30-day history, inspect specific failed records, and receive automatic
email alerts when error rates exceed 5%.

## Stakeholders and Interests

| Stakeholder        | Interest                                                       |
| ------------------ | -------------------------------------------------------------- |
| Administrator      | Detect and resolve sync failures quickly                       |
| System             | Accurate data flowing from AD; alert on anomalies             |

## Preconditions

1. Administrator is authenticated
2. At least one SyncJob record exists

## Postconditions (Success Guarantees)

1. Admin sees accurate last-sync status and history
2. Alert sent within 5 minutes of a sync with > 5% errors

## Triggers

- Administrator navigates to "Admin → Integration Health"
- System triggers alert automatically after a failed sync

---

## Main Success Scenario — View Health Dashboard

| Step | Actor             | System                                                          |
| ---- | ----------------- | --------------------------------------------------------------- |
| 1    | Admin navigates to "Integration Health" |                                        |
| 2    |                   | System fetches last SyncJob for AD sync                         |
| 3    |                   | System renders: Status (✅/❌), Timestamp, Counts summary        |
| 4    |                   | System renders 30-day history table: date, status, counts       |
| 5    | Admin clicks on a failed job |                                                      |
| 6    |                   | System fetches SyncError records for that job                   |
| 7    |                   | System renders error details: ExternalId, error message, retries |

## Extensions (Alternative Flows)

### Automatic Alert Scenario

| Step | Actor                   | System                                                        |
| ---- | ----------------------- | ------------------------------------------------------------- |
| 1    | Sync job completes with errors |                                                        |
| 2    |                         | System calculates error rate = Errors / TotalProcessed        |
| 3    |                         | If > 5%: publish AlertTriggered event                         |
| 4    |                         | F-006 sends alert email to all administrators                 |

### 5a. No Errors in Selected Job

| Step  | Actor          | System                                                        |
| ----- | -------------- | ------------------------------------------------------------- |
| 5a.1  |                | System shows "No errors for this sync run" empty state        |

### 3a. No Sync Jobs Exist Yet

| Step  | Actor          | System                                                        |
| ----- | -------------- | ------------------------------------------------------------- |
| 3a.1  |                | System shows: "No sync jobs found. Run initial sync."         |

## Special Requirements

- **Performance**: Health page load < 2 seconds
- **Security**: Only Administrator role can view integration health
- **Retention**: SyncJob history retained for 90 days

## Technology and Data Variations

- **Alert Channel**: Email via F-006 notification pipeline

## Frequency of Occurrence

- Expected: Admins check health page 1–2 times/week
- Automatic alerts: 0–2/month (only on failures)
