## Brief Description

A Department Manager views a report showing average, median, min, and max approval times grouped
by approver and department. Approvers with average approval time > 5 business days are highlighted
as bottlenecks. Report covers a selectable date range.

## Stakeholders and Interests

| Stakeholder        | Interest                                                       |
| ------------------ | -------------------------------------------------------------- |
| Department Manager | Identify bottlenecks to improve approval SLA                   |
| HR Operations      | Monitor compliance with 48-hour approval target                |

## Preconditions

1. User is authenticated with DM or Administrator role
2. Completed approval ApprovalStep records exist for the period

## Postconditions (Success Guarantees)

1. Report rendered with accurate approval time metrics
2. Bottleneck approvers highlighted (> 5-day average)

## Triggers

- User navigates to "Reports → Approval Times"

---

## Main Success Scenario

| Step | Actor             | System                                                          |
| ---- | ----------------- | --------------------------------------------------------------- |
| 1    | DM navigates to "Reports → Approval Times" |                                     |
| 2    |                   | System shows date range selector (default: last 30 days)        |
| 3    | DM selects date range and clicks "Generate" |                                    |
| 4    |                   | System queries ApprovalStep records for the period              |
| 5    |                   | System calculates per-approver: avg, median, min, max (business days) |
| 6    |                   | System renders table: approver, avg, median, min, max, total approvals |
| 7    |                   | Approvers with avg > 5 days highlighted in orange               |
| 8    |                   | System renders department-level aggregate row                   |

---

## Extensions (Alternative Flows)

### 7a. No Bottlenecks Found

| Step  | Actor          | System                                                       |
| ----- | -------------- | ------------------------------------------------------------ |

| Step  | Actor          | System                                                       |

---

## Special Requirements

- **Calculation**: Business days only (Mon–Fri); excludes weekends
- **Security**: DM sees only their department's approvers
- **Performance**: Report generation < 5 seconds

## Technology and Data Variations

- **Time Calculation**: From VacationRequest.CreatedAt to ApprovalStep.ActedAt (Level=Department)

## Frequency of Occurrence

- Expected: ~1 report/manager/month
